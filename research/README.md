# Research

One-off research. Nothing here is imported by the app, the site or the ad.

- `recon/` — competitor teardown. `REPORT.md` is the write-up, `MEASUREMENTS.md` and `territory.md` back it up, `findings.json` / `palette.json` hold the data, `shots/` has about six screenshots per competitor (around 45 MB) and `scratch/` holds scraped pages. `survey.py`, `classify.py` and `tight.py` produced them.
- `lipsync/` — notes for the lip-synced intro of the UGC ad (`flux-still-prompt.md`, `hook-line1.wav`). The finished clip is meant to be `ad/public/ugc/intro.mp4`, which is not in the repo yet, so `npm run render:ugc` in `ad/` will fail until it is added.
